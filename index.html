        設定

        AIの実行環境

        「一度に読める長さ」は LM Studio 側のモデル読み込み設定（Context Length）で変えてください。

        Gem の「カスタム指示」と「知識」に当たります。ここでの変更は、このブラウザにだけ保存されます。全員の既定値を変えるには assets/prompts.js を編集してください。

        対象

        このブラウザに保存しているもの

        • 接続先・モデルなどの設定
        • 「プロンプト」で編集した指示文と参考資料（編集した場合のみ）

        保存していないもの

        • 入力した本文、読み込んだファイル、AIとの対話。ページを閉じると消えます。残したいときは「記録を書き出す」か「作業を保存」でファイルにしてください。

        準備と使い方

        このツールは、あなたのPCで動くAI（ローカルLLM）に直接つながります。準備は最初の1回だけです。

        1. Ollama を入れる。 ollama.com から Windows 版をダウンロードしてインストールします。
        2. モデルを取得する。 PowerShell を開いて実行します（数GBのダウンロード）。
          ollama pull gemma3:12b

          メモリ16GB程度なら gemma3:12b、8GB程度なら gemma3:4b が目安です。日本語が得意な新しいモデルが出ていれば、それでも動きます。

        3. この画面からの接続を許可する。 Ollama は最初、ブラウザで開いたサイトからの接続を断る設定になっています。PowerShell に次を貼り付けて Enter を押します（何も表示されなければ成功です）。

          このあと Ollama の再起動が必須です。タスクバー右下（「^」の中）の Ollama アイコンを右クリック →「Quit Ollama」で終了し、スタートメニューから Ollama を起動し直してください。開いたままの PowerShell から起動すると設定が反映されないことがあります。

          確かめ方：PowerShell で次を実行し、200 と出れば許可済み、403 なら未設定か再起動前です。

          ほかの用途で OLLAMA_ORIGINS をすでに設定している場合は、上書きせずカンマ区切りで追記します。

        4. ブラウザの許可。 Chrome や Edge で「ローカルネットワーク上のデバイスへのアクセス」の許可を求められたら「許可」を選びます。
        5. つなぐ。 右上の「設定」→「接続を確かめる」を押し、モデルを選びます。うまくいかないときは、どの段階で止まっているかと直し方がその場に表示されます。

        アドレスの 11434 は Ollama の標準の番号です。Ollama の設定（OLLAMA_HOST）で番号を変えていない限り、変更する必要はありません。

        1. Ollama を入れる。 ollama.com から Mac 版をインストールします。
        2. モデルを取得する。 ターミナルで実行します。
          ollama pull gemma3:12b
        3. この画面からの接続を許可する。

          メニューバーの Ollama を終了して、もう一度起動します（Macを再起動したら再実行が必要です）。

        4. つなぐ。 「設定」→「接続を確かめる」。
        1. LM Studio を入れて、モデルをダウンロードする。 画面上の検索から日本語に強いモデルを選びます。
        2. サーバーを起動する。 Developer（開発者）画面でサーバーを Start し、設定の Enable CORS をオンにします。
        3. つなぐ。 この画面の「設定」で「LM Studio など」を選び、アドレスを http://localhost:1234 にして「接続を確かめる」。

        入力したものはどこに行く？

        • 本文・ファイルの読み取り、個人情報らしき語のチェック、文字数の計測は、すべてこのブラウザの中で行います。
        • AIへの送信先は、このPCの中の AI サーバー（localhost）だけです。それ以外への通信は、ページの通信制限（CSP）でブラウザが止めます。
        • 本文や対話はこのブラウザにも保存しません。ページを閉じると消えます。

        うまく動かないとき

        • 接続できない： Ollama が起動しているか、手順3の許可設定のあと Ollama を再起動したかを確認してください。ブラウザのアドレスバー左のアイコン →「サイトの設定」で、ローカルネットワークへのアクセスが「許可」になっているかも確認します。
        • 途中で話が噛み合わなくなる： 文章が長いと、AIが古いやりとりを忘れます。「設定」で「一度に読める長さ」を増やすか、「新しく始める」でやり直してください。
        • 点数の表が出ない： 小さなモデルは決まった書式を守れないことがあります。「再生成」を押すか、大きめのモデルに替えてください。
